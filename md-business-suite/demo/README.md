# MD Business Suite — HTML landing-page export

A static HTML/CSS rendition of the theme's front page. No build step, no JavaScript, no frameworks.

* `index.html` — the page. Edit the copy directly. Edit the `<title>` and meta description before going live.
* `css/style.css` — all styling (same colour and type tokens as the WordPress theme).
* `svg/` — illustrations, icons and placeholders. Replace with your own images.

Fonts (Sora + Inter) load from Google Fonts via the `<link>` in the `<head>`; remove that line to use the local system-font fallbacks only.
The contact form is a static placeholder: point its `action` at your form service or email provider before going live.
