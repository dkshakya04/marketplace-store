FAQ

How do I install the theme?

Upload the downloaded md-business-suite.zip as-is in Appearance → Themes → Add New → Upload Theme → Install Now → Activate. No unzipping needed. Documentation and the HTML export are inside the theme's docs/ folder.

Which WordPress and PHP versions does it need?

WordPress 6.4 or newer (block/Full Site Editing theme, theme.json v3) and PHP 7.4 or newer. Tested up to WordPress 6.8.

Do I need Elementor or another page builder?

No. Everything is built with core WordPress blocks and edited in Appearance → Editor. No builder, no shortcodes and no required plugins.

Can I change the colours and fonts?

Yes. Appearance → Editor → Styles lets you edit the palette (Base, Cream, Stone, Slate, Navy, Ink, Lime) and font families; all patterns update automatically. Google Fonts can be disabled with a filter so only local fonts are used.

Are photos or images included?

No stock photos are bundled. The theme ships lightweight SVG illustrations, icons and placeholders; replace them with your own images from the Media Library (Image block → Replace).

What about updates, support and refunds?

Updates to version 1.x are free for past buyers through the platform you purchased on. Support: reply to your order email. As with all digital downloads, refunds are only issued if the files are defective and cannot be fixed.
