About this product

Python kit that generates every AI coding tool's config (AGENTS.md, Cursor, Copilot, Gemini, Kiro, Windsurf, Cline, Roo + 18 more) from one .claude/ folder and hands a session from one tool to the next with transcript reading and hooks, so you stop in Claude Code and continue in Cursor without re-explaining.

You start a task in Claude Code. It hits its usage limit, or you want to try the same task in Cursor, Codex or Gemini CLI. The new tool knows nothing, so you paste the goal again, explain what was done and what the next step was. Meanwhile every tool wants its own copy of your rules, agents and slash commands, and they drift apart. The AI Handoff Kit fixes both problems with plain Python 3 and no dependencies.

Session handoff that survives a DEAD session

Every tool reads and writes the same .ai/HANDOFF.md (now working on / done / next / blockers). scripts/ai/handoff.py adds the automatic layer: it reads Claude Code, Codex and Gemini CLI transcripts straight from disk, and hooks log every prompt and reply of Cursor, Copilot, Kiro and Windsurf to a git-ignored event log. Open a second tool, say "continue", and it sees the previous session's requests, the last thing the AI said, the edited files, how the session ended and the git state. It warns when two sessions were running at the same time. Tools with hooks get a [Session handoff] notice injected at session start; all others are told by their rule file to run handoff.py status first.

One source of truth for agents, skills and rules

Keep agents in .claude/agents, slash commands in .claude/skills and rules in CLAUDE.md. python3 scripts/ai_sync.py generates everything else, 36 files for a project with one agent and one skill: AGENTS.md, GEMINI.md, QWEN.md, Codex agents and hooks, Cursor rules, commands, agents and hooks, Copilot instructions, agents, prompts and hooks, Gemini agents, commands and settings, Kiro steering and hooks, Windsurf rules, workflows and hooks, Antigravity workflows, Cline, Roo, Amazon Q, Continue, Junie, Trae, Qwen settings and Aider config. Abacus AI, Zed, OpenCode, Amp, Jules, Warp, Devin, Factory, Kilo and Augment read the generated AGENTS.md natively. Every copy carries a GENERATED stamp and --check tells you when it is stale.

An installer that never overwrites

python3 install.py install . adds files only when they are missing, merges hook entries into .claude/settings.json, appends two lines to .gitignore and one section to CLAUDE.md. Existing agents, skills, code and configs stay as they are; run it twice and the second run changes nothing. If a project already runs its own multi-AI hub (a hand-written AGENTS.md, its own sync tool, own Cursor hooks) it stops before touching anything. --update upgrades an earlier install and keeps your handoff data.

FAQ

Does it work with Claude Code and Cursor together, and which other tools does it support?

Claude Code reads the source files directly (CLAUDE.md, .claude/agents, .claude/skills) and gets hooks merged into .claude/settings.json. The generator writes AGENTS.md plus native files for Codex (agents, hooks), Cursor (rules, commands, agents, hooks), GitHub Copilot (instructions, agents, prompts, hooks), Gemini CLI (GEMINI.md, agents, commands, settings with hooks), Kiro (steering, hooks), Windsurf (rules, workflows, hooks), Antigravity, Cline, Roo, Amazon Q, Continue, Junie, Trae, Qwen and Aider. Abacus AI, Zed, OpenCode, Amp, Jules, Warp, Devin, Factory, Kilo and Augment read AGENTS.md natively. The guide has the full table.

How is this different from the free AGENTS.md generators?

Those write a rules file; this kit does that and adds the session handoff. handoff.py reads Claude Code, Codex and Gemini CLI transcripts from disk and the hooks log prompts and replies of the other tools, so the next tool sees the last request, the last answer, edited files and git state. It also generates subagents and slash commands (not only rules), wires hooks for seven tools, warns about parallel sessions, and installs without overwriting anything. You pay for the working combination and 1.x updates as vendors change their formats.

Will it overwrite my existing CLAUDE.md, AGENTS.md, Cursor rules or hooks?

No. Existing files are never replaced. .claude/settings.json hook entries are merged (your hooks and permissions kept), .gitignore and CLAUDE.md are appended to. If you have a hand-written AGENTS.md or your own sync tool, the installer stops before changing anything and explains why; move that content into CLAUDE.md or use --coexist with a different slug.

What do I need installed?

Only Python 3.8 or newer. PyYAML is optional (the generator has its own parser for the config file). No pip packages, no accounts, no network access. Linux, macOS and Windows with Python on the PATH. The AI tools themselves are yours; the kit only writes the files they read.

Does it work without git, or in a project that is not JavaScript or Python?

Yes. The kit is language-agnostic; the installer only reads package.json, pyproject.toml, composer.json, Makefile, Cargo.toml or go.mod to pre-fill the project block. Without git the repository sections of the resume brief are empty and auto-commit stays off.

Is my prompt data sent anywhere or committed?

Nothing leaves the machine. The hook event log (.ai/handoff/events.jsonl) and the activity log are added to .gitignore because prompts can contain private data; only .ai/HANDOFF.md and .ai/decisions.md are meant to be committed. Transcripts are read from your own home folder for the last 14 days.
